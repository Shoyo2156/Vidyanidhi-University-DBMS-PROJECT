# Vidyanidhi University DBMS Project

## Project Description
Database Management System for Vidyanidhi University Examination Management.

## Features
- Student Management
- Subject Management
- Exam Scheduling
- Result Processing
- Exam Fee Tracking
- Expenditure Tracking

## Database Design
- ER Diagram Included
- Normalized up to 3NF

## Technologies Used
- MySQL
- GitHub
- Excel
- Draw.io
- WORD
- NOTEPAD
